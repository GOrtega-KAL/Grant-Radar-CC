# Grant-Radar — panel

Panel público de seguimiento de convocatorias de subvenciones.

Este repositorio contiene **solo lo que el panel necesita** para servirse por
GitHub Pages:

| Archivo | Qué es |
|---|---|
| `index.html` | El panel |
| `convocatorias.json` | Las convocatorias y su análisis |
| `estado_recopilacion.json` | Estado de la última recopilación |

Los dos JSON los publica automáticamente la herramienta que los genera, que
**no vive aquí**.
